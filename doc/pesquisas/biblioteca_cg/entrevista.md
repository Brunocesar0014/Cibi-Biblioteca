# 2. Funcionamento geral da biblioteca

## Pergunta-base 1

**Você poderia explicar, de forma geral, como funciona atualmente o gerenciamento da biblioteca?**

### Perguntas de apoio

* Como vocês fazem o controle da biblioteca hoje?

Hoje atravez de uma planilha no excel, porém a pouco tempo tudo era anotado manualmente. 

* Quais são as principais atividades necessárias para manter a biblioteca funcionando?

Emprestimo, devolução, cadastro de livros, inscrição do leitor e monitoramento de dados

* Como vocês controlam livros e pessoas?

através de planilhas físicas e no excel 

* Como vocês sabem quais livros estão disponíveis, emprestados ou atrasados?

Só é possível saber através de uma busca manual. Normalmente não é eficiente o sufuciente para ter total controle dos dados

## Pergunta-base 2

**Quando um livro novo chega à biblioteca, o que acontece até que ele fique disponível para utilização?**

Após o cadastrados os dados, ele vai diretamente para a estante.

### Perguntas de apoio

* Quem realiza esse processo?

Apenas a gestora.

* Como é feito o cadastro do livro?

são colocados na planilha:

- 1. Titulo
- 2. Autor
- 3. Assunto
- 4. Editora
- 5. id (matrícula)
- 6. Numeração da Prateleira

## Pergunta-base 4

**As pessoas que utilizam a biblioteca são cadastradas ou identificadas? Como?**

É anotado a matricula escolar ou cpf(caso de maior idede).

### Perguntas de apoio

* Como vocês fazem o cadastro dessas pessoas?

são colocados estes dados na planilha.

* Quais informações precisam ser registradas?

- nome
- matricula (ou cpf)

# 5. Devolução e renovação

## Pergunta-base 1

**Como funciona o processo de devolução de um livro?**

Após a devolução do livro, um processo de verificação de integridade é feito e logo depois ele é devolvido a estante. Essa vereficação não é tão profunda, portanto, as vezes não é possível ver se algum livro estiver com uma página danificada por exemplo

### Perguntas de apoio

* O que precisa ser registrado?

livro devolvido, integridade e caso o livro esteja danificado, qual ação será tomada.

## Pergunta-base 2

**Como funciona quando alguém deseja ficar com o livro por mais tempo?**

é possível fazer uma renovação, adicionando mais 30 dias com o livro.

### Perguntas de apoio

* Existe um limite de renovações?

apenas 1

# 7. Livros perdidos, danificados ou retirados do acervo

## Pergunta-base 1

**Como vocês procedem quando um livro é perdido ou não é devolvido?**

caso a pessoa não retorne com o livro não há nada a se fazer, mas se a pessoa informar que o livro foi perdido o mesmo deve trazer outro exemplar do livro ou outro equivalente

## Pergunta-base 2

**E quando um livro é devolvido danificado ou está em condições ruins?**

caso seja danificado gravemente danificado a pessoa deve trazer outro exemplar do livro ou outro equivalente

# 8. Organização física e localização dos livros

## Pergunta-base 1

**Como os livros são organizados fisicamente dentro da biblioteca?**

existe um sistema padrão de classificação chamado "numero de chamada" que é seguido para organizar as prateleiras.

ele utiliza a Classificação Decimal de Dewey (CDD), O código do Autor (Tabela Cutter) e dados complementares (opcional)

## Pergunta-base 2

**Quando alguém procura um livro específico, como vocês descobrem onde ele está localizado?**

normalmente os funcionarios lembram onde está por acabar se acostumando com a organização utlizada.

### Perguntas de apoio

* É possível consultar a localização?

não

* É necessário procurar fisicamente?

sim

## Pergunta-base 3

**Seria útil para vocês se o sistema informasse também onde cada livro ou exemplar está localizado fisicamente?**

seria, pois pouparia tempo
